# Source formatting

- Keep HTML, CSS, and JavaScript readable; do not minify source files.
- Use the repository Prettier configuration and 2-space indentation.
- Run `npm run format` after edits and `npm run format:check` before finishing.
- Use `/* HTML */` for HTML template literals so Prettier formats embedded markup.
- Preserve whitespace-sensitive content and existing behavior when formatting.
- Do not format archived backups or captured reference documents.
